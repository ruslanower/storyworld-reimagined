# 🎲 Хроніки Майстра: Корона Чорної Зірки (Storyworld Reimagined)

Сучасна кооперативна 16-bit HD-2D JRPG пригода з ШІ-Майстром Гри, розроблена на базі React 19, Vite, TanStack Start/Router та Tailwind CSS з піксель-арт візуалом та Blender 2.5D діорамою.

## 🚀 Швидкий запуск

### 1. Веб-застосунок (React / Vite)
```bash
npm install
npm run dev
```
Відкрийте `http://localhost:3000` у браузері.

### 2. Збірка для продакшену
```bash
npm run build
```

## ✨ Ключові можливості
- **Сюжетна кампанія «Корона Чорної Зірки»:** 8 повноцінних актів темного фентезі проти тирана Малґора та Залізної Варти.
- **6 унікальних класів персонажів:** Бард, Розбійник, Містик, Чорнокнижник, Слідопит, Вартовий.
- **Свобода дій та D20:** ШІ-Майстер Гри адаптивно реагує на будь-які репліки чи дії героїв.
- **HD-2D Pixel Art:** 12 анімованих локацій, частинки погоди (дощ, алхімічний дим, іскри), 4 пози для кожного класу та понад 48 предметів інвентарю.
- **2.5D Blender сцена:** `assets/chronicles_hd2d_scene.blend` — діорама з паралаксом та точковим освітленням.
