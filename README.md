# 🎲 Хроніки Граней — Модульна AI-RPG Платформа Пригод

Універсальний вертикальний мобільний застосунок-платформа (9:16) для кооперативних настільних пригод (1–4 гравці) з ШІ-Майстром Гри та 3D-емблемою D20, згенерованою кодом у **Blender 5.2 (`bpy`)**.

## 🚀 Як запустити в 1 клік
Двічі клікніть файл **`Запустити_Гру.command`** у теці `ГРА` (або відкрийте `index.html`).

## ✨ Ключові можливості платформи
- **Вітрина Пригод (Незалежна від сценарію):**
  - 🔥 **Пригода Місяця** — активний щомісячний випуск.
  - 📚 **Архів Пригод** — попередні історії.
  - 💎 **DLC Кампанії** — платні преміум-пригоди (достатньо, щоб DLC було у Хоста кімнати).
  - ➕ **Конструктор / Картриджі (`cartridges.js`)** — додавання будь-якого нового сценарію без змін у коді застосунку.
- **Мережеве Лобі для 1–4 Друзів:**
  - Вхід за 4-значним кодом кімнати (синхронізація через `BroadcastChannel` між вкладками та P2P).
  - **6 Унікальних Героїв на кожну пригоду** з блокуванням дублікатів (якщо гравець 1 зайняв героя, інший гравець не може взяти того самого).
- **Вільний Світ та Розумна Система Кубиків D20:**
  1. **Мирні / інформаційні дії** (запитати дорогу в перехожого, оглянути кімнату) — виконуються **без кидка кубика**.
  2. **Ризиковані та нестандартні ідеї гравця** (залізти у вікно, пустити поштового голуба, виманити всіх криком про пожежу, бій) — ШІ-Майстер оцінює доречність і призначає **кидок D20** з бонусом характеристики та Складністю (DC).
  3. **Провокація нейтральної масовки або хижаків** (наїхати на селян/відвідувачів корчми або спитати дорогу у зграї вовків) — **сам Майстер Гри кидає D20 за реакцію NPC/світу**!
